PAGEHUB · USER GUIDE

普通用户使用帮助

从创建账号，到发布和整理 HTML 页面、连接智能体、收藏常用网站和分享页面。本手册按工作台中的日常操作顺序说明各功能。

截图使用测试环境的 test 账号制作。页面、菜单、收藏示例来自该账号的现有数据；手机号、验证码、密码和访问凭证不会出现在截图中。
01

注册与登录

打开 PageHub 后，登录页提供“登录”和“注册”两个标签。登录时可填写用户名或手机号以及密码。每个手机号只能注册一个账号；注册会同时创建该用户自己的空间，其他用户看不到你的页面和文件。

  1. 选择“注册”，填写用户名、姓名、手机号、验证码和密码。
  2. 选择“获取验证码”，输入页面返回的本地开发验证码，再设置并确认密码。
  3. 选择“注册并立即使用”，注册成功后会自动进入工作空间。
验证码模式：当前环境使用临时开发验证码，不会发送真实短信。它仅用于开发测试，不代表手机号已收到或验证过短信。生产短信服务尚未接入。密码至少 10 位；忘记密码时请联系平台超级管理员处理账号。
02

工作空间

工作空间是登录后的主要页面，提供菜单导航和页面入口。页面卡片按租户菜单顺序展示，卡片显示页面标题、所属菜单、文件大小和日期。可用搜索、菜单分类、排序和分页定位页面。点卡片打开页面；拖动卡片可以交换其顺序。

三种菜单布局

左侧导航
左边以缩进树形显示一级、二级和三级菜单。选择一个分类后，主区域显示对应页面。
顶部导航
菜单显示在内容上方；一级分类可下拉显示子菜单，超出宽度的菜单收在“更多”中。
平铺
主区域以链接目录展示有页面的末级菜单，支持搜索、分类、排序和紧凑/列表视图。点目录项进入该菜单页面。

卡片与页面视图

工作空间面向按菜单浏览和打开页面；“全部页面”面向搜索和管理所有页面。工作空间首页会展示部分页面卡片，使用“查看全部”进入完整列表。宽屏卡片自动增加列数，窄屏自动换行。

03

发布 HTML 页面

在工作空间或“全部页面”选择“上传页面”，可上传 .html、.htm 或 .zip 文件。ZIP 适用于带有图片、CSS、JavaScript 等资源的完整网页，也可作为翻页 HTML 演示上传。

  1. 选择 HTML/HTM 或 ZIP 文件，确认页面标题。单文件大小上限由平台配置（当前默认 20 MB）。
  2. 填写菜单路径，以斜线分隔，例如“业务工具 / 报表 / 月报”。路径中不存在的菜单会自动创建。
  3. ZIP 通常从根目录 index.html 开始；如果实际入口位于子目录，填写 ZIP 入口文件路径。也可在 ZIP 根目录提供 manifest.json。
  4. 选择“上传并发布”，等候后台解析。处理结果可到“上传记录”查看。
菜单挂接规则：页面挂在路径的末级菜单。一个末级菜单只能挂一个页面；有子菜单的父节点本身不能同时挂页面。若目标末级菜单已被占用，请换一个菜单名称，或先在菜单管理新建一个空闲末级菜单。一级、二级或三级节点都可以成为末级菜单。

给现有页面上传新版本时，请从该页面卡片的“页面操作”菜单中选择“上传新版本”。这会更新同一个页面并保留历史版本；普通新上传会创建一个新页面。

04

菜单管理

菜单是用于组织工作空间的分类树，最多三级。一级、二级和三级菜单可以分别作为最终挂接页面的末级节点；父节点如果有子菜单，就不能直接挂页面。菜单名称和顺序可以后续调整。

新增菜单

选择“新增菜单”后，先选一级、二级或三级。新增一级不需要选择父级；新增二级要指定一级父菜单；新增三级要指定二级父菜单。输入名称确认后会显示创建路径。

编辑和拖动

在菜单操作中编辑名称、父级、顺序及导航可见状态。也可拖动菜单名前的拖动柄：在同一父级内可换顺序；拖到其他节点上则调整父子层级。拖动一个有后代的一级或二级菜单时，整棵子树一起移动。系统会校验层级不超过三级；有页面的节点不可作为父菜单。

不想删除页面？菜单只管页面分类。删除菜单不会替代“下架页面”或“彻底删除文件”；如果菜单已包含页面或子菜单，应先在“全部页面”调整挂接，或在菜单管理移动子菜单。
05

全部页面与版本

“全部页面”集中管理当前账号的所有已发布页面，可按标题搜索，也能从卡片进入页面、修改标题或菜单、发布新版本、查看版本记录、进入文件管理、复制访问链接、分享或下架页面。

页面预览

点卡片进入页面。租户管理员为整个租户配置“框架内显示”或“框架外打开”；框架内模式在工作台内嵌入页面，框架外模式在新标签打开。外框架访问仍要取得授权，不能当成永久免登录公开链接。个人设置可调整自己框架外预览授权的有效分钟数。

分享菜单

菜单下至少有一个可分享页面时，可从菜单卡片上的“分享”打开分享设置。一个菜单有多个页面时，可指定本次要分享的页面。公开链接可发给任何持有人；指定账号分享只授权选定账号。

06

文件管理与存储空间

文件管理列出已上传文件、页面版本、上传者、文件大小、时间及菜单挂接路径。左侧目录显示文件夹占用；目录大小包含其下级目录和保留的所有版本。上传 ZIP 后可查看内部文件清单。

下载、删除与空间配额

  • “下载原件”下载当前上传文件；勾选多条后可批量下载（每批最多 100 个、总大小最多 2 GB）。
  • 历史版本可单独删除；当前版本不能作为历史版本删除。版本清理提交后台任务，完成后才释放占用。
  • “下架页面”仅让页面停止访问；文件和全部历史版本仍被保留并继续计入空间。
  • “彻底删除页面及文件”会使页面链接失效并清理该页面所有版本。删除不可撤销，清理完成后才归还配额。
配额查看：账号菜单和“空间设置”显示剩余空间、已用空间和账号配额。平台超级管理员设置每个账号的配额；同一租户内的账号各自计算自己的上传配额。
07

上传记录

上传记录用于追踪原始 HTML 或 ZIP 的解析任务，包含文件名、状态、大小、文件状态、处理结果和上传时间。正在排队或解析的任务会自动刷新；失败时查看“处理结果”中的具体原因。上传成功后可从该记录跳到对应页面的文件管理。

08

网站收藏

网站收藏用于保存外部网站链接，与页面菜单分开管理。可新建、修改、删除收藏，选择一个平级收藏分类，搜索、排序、拖动换序，并下载收藏清单。这里只显示外链收藏分类，不显示 PageHub 的页面菜单分类。

部分网站会通过响应头拒绝被嵌入，或要求在原网站登录。在框架内显示空白、拒绝连接或登录不正常时，使用卡片里的新标签页打开入口。PageHub 只能保存收藏信息，不能替外部网站进行身份验证。

09

我的分享与共享给我

菜单或页面卡片上的“分享”可以建立公开链接，或将页面指定给一个 PageHub 账号；页面分享固定对应创建时选择的页面版本。

我的分享
查看页面、分享方式、接收账号、分享时间、有效期和状态；可复制有效公开链接、撤销访问，或删除列表记录。
共享给我
接收账号登录后，在“共享给我”打开页面。可以将记录从自己的列表移除，不会删除分享者的页面。
过期/撤销
过期或撤销后无法再访问；永久有效的分享仍可由分享者随时撤销。
分享范围：公开链接不要求登录，不能转发给不应访问的人；指定账号分享只对被选定并登录的账号生效。分享失效只影响访问权限，不删除原页面。
10

智能体与 MCP

MCP 让支持 MCP 的智能体读取菜单和页面，也可在读写凭证授权下上传 HTML/ZIP、按路径创建菜单、查询上传任务及页面链接。配置入口独立位于工作台顶部的“MCP 接入”。

  1. 给凭证起一个可辨认的名称。发布页面需要读写权限；只读凭证不能上传或创建菜单。
  2. 选择“创建凭证”。新凭证令牌只在创建后显示一次。
  3. 确认正文中的 Authorization 请求头自动使用新令牌，再选择“复制给智能体”，把配置和指令交给受信任的智能体。
  4. 让智能体按用户意图调用上传工具。它应先查菜单、上传 HTML/ZIP，并等待解析任务状态为成功，再返回页面标题和访问链接。
  5. 不再使用的凭证可以删除/撤销；旧凭证立即失效。凭证默认有效期 90 天。
凭证保护：Bearer 令牌相当于账号访问凭证。只发送给你信任的智能体，不要放进公开文档、聊天群或截图。凭证不会再次显示；丢失后创建新凭证并删除旧凭证。

如果智能体提示菜单不能挂接，请在菜单管理中创建空闲末级菜单，或让智能体使用新的菜单名称。父级菜单有子菜单、或已有页面的末级菜单都不能再接另一个页面。

11

空间与个人设置

右上角“工作台设置”打开工作空间各功能；紧邻其右侧的问号图标打开本帮助。账号菜单可查看剩余空间、进入账号与空间设置、修改密码和退出。

全租户共用
导航布局（左侧/顶部/平铺）及页面打开方式由租户管理员配置，该空间内的用户共享这些设置。
个人设置
浅色/深色主题、平铺目录紧凑/列表视图，以及本人框架外访问授权有效分钟数。
存储空间
按当前账号的用量与配额单独统计。历史版本会继续占空间，清理任务完成后才释放。

框架外授权时长只用于获取页面的短期访问授权。页面链接仍受账号会话保护；它不是永久公开分享。若需匿名预览，请创建并妥善管理公开分享链接。

12

常见问题

上传成功了，菜单里没有显示页面

检查上传记录是否为“已发布”，并检查上传路径末级菜单有没有被隐藏。若目标路径的父级菜单不可见，整个分支也不会出现在导航中。

为什么二级菜单不能挂页面？

若它已经有子菜单，它是父节点，页面应挂到下一级空闲节点；如果没有子菜单，它可以作为末级节点挂一个页面。一级菜单同样遵循这个规则。

下架后空间没有变小

下架保留页面文件和版本以便恢复或审计。需要释放空间时，进入文件管理彻底删除历史版本，或彻底删除页面及其全部文件，然后等待清理任务完成。

收藏的网站显示页面不存在或空白

检查收藏网址是否有效。外部网站可能禁止被嵌入；在收藏页尝试新标签页打开。访问权限和登录由外部网站控制。

MCP 上传没有成功

检查令牌是否有效且有读写权限；让智能体轮询上传任务到最终状态，并检查具体错误。菜单已经挂页面或是仍含子菜单的父级时，须指定空闲的末级菜单。

框架外页面无法打开

先登录工作台，再从页面入口打开以刷新授权。授权到期后回工作空间重新打开。若想让未登录者预览，应使用公开分享，而不是普通页面访问地址。

验证码收不到

当前开发环境不会发短信，验证码会显示在注册表单附近的提示中；这个功能不能证明手机号已经接收短信。

如果菜单、页面或空间配额仍有问题，请把页面标题、上传时间和任务失败原因提供给平台超级管理员排查。不要向他人发送 MCP 凭证或公开分享链接。
