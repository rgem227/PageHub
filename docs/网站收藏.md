# 网站收藏

从顶部“工作台设置 → 网站收藏”进入，默认显示分类分组的紧凑卡片，可切换“收藏管理列表”。收藏分类独立于页面菜单，是租户内的平级名称；页面只显示至少有一条收藏的分类和外链，不显示上传页面或页面菜单（例如“演示中心”）。两种视图共用服务端名称/网址/备注搜索、分类筛选和排序，每页 40 项。

## 新增与维护

- 名称、HTTP/HTTPS 网址必填。分类可选现有菜单，或填写最多三级的新路径；未指定时放入“未分类”。分类的名称、顺序、层级和显示状态在菜单管理中统一维护。
- 可设置备注、顺序和独立打开方式。卡片名称自动换行，备注最多两行，完整备注可在编辑界面查看。
- 同分类新建相同网址，或把网址/分类改为已有组合时，需确认后保存；只改名称、备注和打开方式不会重复要求确认。批量移动保留重复记录，防止合并分类时丢失备注。
- 列表支持当前页勾选、批量移动和批量删除。删除只清除平台收藏记录，不操作目标网站；空分类可删除，含收藏的分类需先移动或删除其中收藏。
- 收藏只保存链接，不计入上传文件配额；工作空间统计中单独计数。

## 工作空间展示

收藏与左侧、顶部、平铺的页面菜单互不影响。收藏分类不支持二级/三级层级；页面菜单的创建、隐藏或删除不会改变收藏分类。

平铺继续只展示末级菜单；打开内容后不混排首页入口。原“全部页面”和“文件管理”继续管理上传内容，文件大小及删除行为保持原规则。

## 外链打开

默认新标签页打开，使用 `noopener,noreferrer`。也可单独设置“尝试框架内”，此设置不受租户对上传页面的打开方式影响。

框架内使用受限 iframe 和紧凑工具栏，始终提供刷新、新标签页打开和返回。8 秒后提示：如果空白、拒绝连接或无法登录，可以改用外部打开。提示不是故障判定，也不自动跳转。禁止嵌入可能由 X-Frame-Options、CSP frame-ancestors、HTTPS 混合内容或浏览器登录限制导致。

不提供网页代理，不绕过第三方网站限制，不抓取网页元信息，不保存第三方账号或 Cookie。iframe 未开放同源权限，部分网站因此可能不兼容，可使用外部打开。

## MCP

网页与 MCP 共用收藏业务、校验和租户范围；只读凭证不能新增、修改或删除。支持：

| 工具 | 用途 |
| --- | --- |
| `search_bookmarks` | 名称、网址、备注搜索；按平级 `category_id` 筛选；分页最多 100 项 |
| `create_bookmark` | 新增收藏，menu_path 自动创建最多三级分类，默认 external |
| `get_bookmark` | 读取收藏及稳定平台 access_url，访问者需登录所属租户 |
| `update_bookmark` | 只修改提供的字段；menu_path 可移动分类并创建缺失菜单 |
| `delete_bookmark` | 删除收藏链接，保留审计记录 |

示例参数：

```json
{
  "title": "FastAPI 开发文档",
  "url": "https://fastapi.tiangolo.com/",
  "menu_path": ["常用网站", "开发文档"],
  "description": "Python API 框架文档",
  "open_mode": "external"
}
```

网站外部地址为 `url`，平台登录入口为 `access_url`，二者区别明确。API 路径为 `/api/bookmarks`、`/api/bookmarks/{id}`、`/api/bookmarks/batch-move`、`/api/bookmarks/batch-delete` 和 `/api/bookmark-categories`；API PATCH 接收完整表单，分类使用 `category_id`，MCP update 工具支持局部字段更新。

## 部署与示例

执行 `backend/bootstrap.py` 将增量创建 bookmarks 表、索引和 RLS，并授予现有应用账号权限。没有新增依赖；已有租户、菜单、上传文件和账号密码保留。

`scripts/publish_bookmark_demos.py` 通过真实 MCP SDK 给 admin/test 各添加 4 个不同网站，分类为“开发文档”和“日常资源”；按标题复用记录，结束撤销临时凭证，不修改账号偏好。外部网站实际可访问性及嵌入策略可能变化，示例默认外部打开。无密钥结果保存在 `.runtime/bookmark-demos.json`。
