# PageHub · HTML 页面集成平台

Vue 3 + TypeScript + Element Plus 前端，FastAPI + PostgreSQL 后端，使用 MCP Python SDK 提供 Streamable HTTP 工具。完整需求见 [需求说明](AI生成页面集成平台-需求说明.md)。

## 本地启动（Windows）

需要 Python 3.12+、Node.js 22.12+ 和可连接的 PostgreSQL。使用独立数据库 `html_hub` 和非超级用户运行账号 `html_hub_app`，不会修改其他数据库。

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r backend/requirements.lock.txt
cd frontend
npm ci
cd ..
./.venv/Scripts/python.exe backend/bootstrap.py
./scripts/start-dev.ps1
```

初始化脚本交互输入 PostgreSQL `postgres` 账号密码；主机默认 `127.0.0.1:5432`，可通过 `HUB_PG_HOST`、`HUB_PG_PORT` 和 `HUB_PG_PASSWORD` 环境变量覆盖。运行时使用自动生成的应用账号，不使用 postgres。`.env`、初始凭据和本地文件均已排除版本控制。

- 平台：启动脚本会探测局域网 IPv4 并打印访问地址，例如 `http://192.168.x.x:5173`
- API 文档：同一地址的 `:8000/docs`
- MCP：在平台顶部“MCP 接入”中查看本机局域网 IP 地址（需要末尾的 `/`）。
- 隔离内容服务：http://127.0.0.1:8011
- 超级管理员用户名：`admin`；随机临时密码保存在 `.runtime/admin-credentials.txt`。首次登录必须修改，保存后请删除该凭据文件。

普通用户直接在登录页注册，手机号必填且全平台唯一；开发验证码会在注册界面显示，不发送短信。注册成功后自动创建个人租户并进入工作空间。

停止服务：`./scripts/stop-dev.ps1`。该脚本只停止本项目记录且启动时间匹配的进程。日志位于 `.runtime/*.log`。

Linux/macOS 可在 `backend` 目录分别运行：

```sh
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
python -m uvicorn app.content:app --host 127.0.0.1 --port 8011 --no-access-log
python -m app.worker
```

在 `frontend` 目录运行 `npm run dev`。开发环境需确保 `.env` 中的网页和内容地址与实际服务一致。

## 已实现的主要流程

- 两类角色：平台超级管理员与普通用户。
- 注册、用户名或手机号登录、修改密码和登录会话撤销。
- 注册自动创建个人租户；超级管理员管理租户、用户归属、用户状态及租户存储配额。
- PostgreSQL RLS 和接口租户校验；非超级用户运行账号。
- 最多三级菜单、上传自动创建菜单，可调整名称、上级菜单、顺序及显示状态；移动时保留子菜单和页面关联。
- 顶部“工作台设置”按钮集中管理功能，左侧或顶部导航仅展示租户菜单；注册必填字段有红色星号，字段校验使用中文提示。
- 左侧导航可通过顶部折叠按钮隐藏或展开；隐藏后内容自动铺满可用宽度，正在浏览的 HTML 不重新加载。展开后保留原菜单状态。
- 左侧和顶部多级菜单只展示实际菜单名称；父级展开、收起子菜单，不再自动增加“查看此分类”入口。
- 顶部一级菜单统一高度与间距，下拉采用圆角浮层并适配深浅主题；宽度不足时自动收进末尾“…”按钮，点击可展开剩余菜单及其下级。菜单新增、改名、删除及窗口缩放后自动重新计算，仅影响顶部导航。
- 左侧菜单名称前显示小图标：一级按顺序轮换 24 种内置图标，二级统一四宫格分类图标，三级统一页面；顶部和平铺不增加这组图标。
- 租户级顶部/左侧/平铺布局，蓝色浅色与深蓝主题。平铺采用紧凑网站链接目录或列表，支持 20 字长名称、路径提示、菜单/页面搜索、分类筛选、排序及服务端分页；个人展示偏好保存到账号。内容独立打开，返回恢复筛选、页码与浏览位置。
- 内容使用全部可用宽度，左侧导航与内容保留桌面 24px 间距；空间设置可选择“框架内显示”或“框架外打开”，后者在新标签页打开隔离内容，仍需登录授权。直接访问稳定页面链接时，按外部模式在当前标签页跳转到授权内容。
- 工作空间为默认首页；全部页面采用紧凑卡片，常规桌面四列，按可用宽度自动调整为一至五列，长名称自动换行。
- 统一 PAGE HUB 渐变品牌、“如”字标识及浏览器图标，浏览器标题为 PageHub。
- HTML/HTM/ZIP 上传、持久化任务队列、独立 worker、manifest 解析、页面发布、版本回滚及稳定链接。
- 独立内容服务、短时访问授权、受限 iframe 和 CSP sandbox。
- MCP 菜单与页面查询、自动创建菜单、HTML/HTM/ZIP 上传、更新与任务查询；只读/读写凭证、有效期和撤销。页面较多时使用 `search_pages` 搜索分页（最多 100 项），`upload_html` 的可选 `filename` 保留原始文件名；旧调用兼容。
- 超级管理员按用户/租户统计页面、上传、版本及逻辑存储用量，查看当前主机资源和审计事件。
- 平台管理使用独立控制台：概览、租户、用户、上传任务、文件管理、资源和审计；按栏目读取数据，服务端筛选分页，详情与编辑使用抽屉。用户空间中的页面、菜单和上传记录同样支持服务端搜索分页。
- “工作台设置 → 文件管理”集中显示上传文件、版本、目录大小、上传时间/上传者和菜单挂接状态；支持查看 ZIP 内部文件与目录大小、切换当前版本、单个/批量删除历史版本，以及彻底删除页面全部文件。后台清理完成后才释放账号和租户配额，失败可重试；上传记录继续保留。超级管理员可在平台文件管理中跨租户筛选和清理。详见 [文件管理与空间清理](docs/文件管理与空间清理.md)。
- 顶部账号菜单提供剩余空间、账号设置、修改密码与退出入口；不增加登录入口或角色。
- “工作台设置 → 网站收藏”支持独立平级分类、分类紧凑卡片、管理列表、搜索分页、新增编辑、重复网址提醒、排序与批量移动删除。收藏只管理外链，不与租户菜单或上传页面混合；MCP 可查询、新增、维护和删除收藏。详见 [网站收藏](docs/网站收藏.md)。

## 页面包

`examples/` 提供欢迎页面、经营看板和费用计算器三个独立 HTML，均无需外网资源。可以分别挂在一级、三级和二级菜单下，切换“空间设置 → 导航布局 → 平铺”时，均以末级菜单名称展示；一个菜单只有一个页面时直接打开，多页面时独立展示该菜单页面列表。框架内打开后隐藏平铺卡片和其他页面；框架外在新标签页打开，原标签页保留菜单入口。

单 HTML 可直接上传。ZIP 默认入口为根目录的 `index.html`，支持相对路径 CSS、JavaScript 和图片。可放置根目录 `manifest.json`：

```json
{"title":"销售报表","entry":"index.html","menu":["业务工具","报表","月报"]}
```

上传表单参数优先于 manifest；没有菜单路径时使用“未分类”。超过三级、危险路径、重复 ZIP 路径、异常压缩比和超额文件会拒绝发布。ZIP 解析由 worker 完成，网页自动轮询待处理任务。

## MCP 连接

登录后点击顶部独立的“MCP 接入”按钮创建凭证。凭证仅展示一次，默认有效期 90 天；需要上传时使用读写凭证。

创建后会将新凭证自动填入配置的 `headers.Authorization`，可一键复制完整 JSON。关闭弹窗后在当前 MCP 页面仍可复制；离开页面或刷新后不会恢复明文。`scripts/start-dev.ps1` 会探测默认路由对应的局域网 IPv4，将前端、API、内容服务分别绑定到 `0.0.0.0`，并把局域网地址用于站点来源、内容地址和 MCP 地址。启动后使用脚本打印的 `http://<局域网IP>:5173` 访问；也可通过 `.env` 的 `MCP_PUBLIC_URL` 设置部署地址。Windows 防火墙需允许相应端口的入站连接，其他设备才能访问。

```json
{
  "mcpServers": {
    "page-hub": {
      "url": "http://<本机局域网IP>:8000/mcp/",
      "headers": {"Authorization": "Bearer <平台生成的凭证>"}
    }
  }
}
```

可用工具：`list_menus`、`create_menu`、`list_pages`、`upload_html`、`upload_zip`、`get_upload_status`、`get_page_url`。客户端的远程 MCP 配置字段可能不同，应按客户端文档配置 HTTP 端点和请求头。

上传示例参数：

```json
{"html":"<html><title>月报</title><h1>月报</h1></html>","menu_path":["业务工具","报表","月报"]}
```

调用 `upload_html` 或 `upload_zip` 后使用返回的任务 ID 查询 `get_upload_status`。更新页面时传入 `page_id`。没有凭证时返回注册 URL；当前通过网页完成手机验证，不开放未认证自动创建账号。

## 测试与构建

```powershell
cd backend
../.venv/Scripts/python.exe -m pytest -q
cd ../frontend
npm run build
cd ..
npm ci
npx playwright test
```

后端集成测试使用已初始化的数据库，创建独立测试租户并清理自身记录；不要与生产数据库共用配置。浏览器测试需先启动本地服务，默认使用本机 Microsoft Edge，会留下以 `browser_` 开头的演示账号和页面，供检查界面使用。

只读 API 并发测试：

```powershell
$env:HUB_LOAD_TOKEN = '<只读 MCP 凭证>'
./.venv/Scripts/python.exe scripts/load_test.py --concurrency 1000 --rounds 3
Remove-Item Env:HUB_LOAD_TOKEN
```

该测试以 1000 个客户端同时请求菜单、页面和工作空间接口，记录延迟及错误率。它不等同于持续压力或生产容量验收；正式验收还需规定 SLA、请求比例、持续时间，并覆盖上传和 MCP 负载。

## 部署边界与待完善项

- 账号存储配额默认 1024 MB（1 GB），在“平台管理 → 用户管理 → 管理”设置；用户可在账号菜单及“空间设置”查看剩余空间。账号与租户两种配额同时生效，提高账号配额时需留意租户总限制。用量按上传者累计所有保留版本；调整归属不会重置用量，下架不释放空间，文件彻底删除完成后归还原上传账号及文件所属租户的配额。

- 真实短信服务尚未接入。生产环境禁止使用开发验证码；需接入供应商后才能开放生产注册。
- 当前支持本地文件存储和 S3 兼容存储。S3 模式需预先创建私有 bucket；生产环境必须配合 Nginx 内部转发，避免 Python 转发文件内容，参考 `deploy/nginx.conf.example`。S3/Nginx 部署组合尚未联调。
- 内容网关仍校验租户、用户和页面状态；临时内容 URL 是短期访问凭证，不应分享给他人。平台稳定链接仍要求登录。
- 内容 sandbox 不允许同源权限、表单提交、弹窗和顶层导航；需要这些浏览器能力的 HTML 可能无法完整运行，需按实际页面逐项评估权限。
- 页面“下架”和租户删除采用逻辑删除，保留文件仍占配额；文件管理支持手动彻底删除页面或历史版本，使用独立 worker 执行，保留清理记录和审计。尚未实现按保留期限自动清理、备份恢复演练。正常完成上传任务后清理原始暂存；进程异常退出或删除失败留下的原始暂存和未入库残留仍需运维检查。S3 永久清理会检查 bucket 版本控制并删除该版本目录的历史对象版本/删除标记，需要相应权限；真实 S3/Nginx 部署仍需联调。
- 资源指标是当前 API 主机及页面版本的逻辑用量；多主机指标聚合、对象存储实际容量和历史监控曲线尚未接入。
- 公开分享默认不开放；手机号更换、忘记密码、自助注销和 MCP 自动注册尚未实现。当前超级管理员可创建账号并分配租户，返回一次性临时密码。
- API 使用同步数据库池并由 FastAPI 线程池处理，MCP 同步工具也移出事件循环；连接池上限为每进程 15。多实例部署需统一规划连接总数，可根据负载增加 PgBouncer。
- 对外部署需启用 HTTPS、配置独立内容域名、反向代理大小与连接限制、日志保留、数据库和对象存储备份。
